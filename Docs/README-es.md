### ⭐ Proyectos y Laboratorios Destacados

#### 🔐 [Wazuh SIEM & Blue Team Security Cases](https://github.com/SantiagoDandrea)
Implementación completa de un entorno SIEM centralizado y resolución de casos defensivos.
* **Componentes:** Wazuh Manager, Indexer, Dashboard y despliegue de agentes en entornos mixtos Linux y Windows.
* **Detección & FIM:** Monitoreo de integridad de archivos críticos (`/etc`), detección de modificaciones y adición de binarios no autorizados.
* **Casos de Análisis:** Detección y contención de fuerza bruta SSH con Fail2ban, correlación de accesos anómalos y escalamiento de privilegios (`sudo`).

#### 🌐 [Web Application Security Lab](https://github.com/SantiagoDandrea/Web-Security-Lab)
Laboratorio de auditoría, explotación y remediación de vulnerabilidades web enfocado en código seguro y sanitización de inputs.
* **OWASP Juice Shop:** Explotación de DOM XSS, evasión de sanitización en Angular, bypass de login con SQLi y manipulación de lógica de negocio.
* **DVWA:** Análisis profundo de SQL Injection (Medium, High y Blind) extrayendo esquemas mediante condiciones booleanas y `UNION SELECT`.
* **PortSwigger Academy:** Exfiltración de sesiones (Stored XSS con Burp Collaborator), manipulación de tokens JWT y evasión de filtros.

#### 📋 [Data Protection & Security Compliance](https://github.com/SantiagoDandrea)
Mapeo técnico-legal y gobernanza de seguridad para entidades con datos sensibles (contexto asegurador/financiero).
* **Marco Normativo:** Requisitos y principios de la Ley Nacional 25.326 (Habeas Data Argentina) y alineación con controles ISO/IEC 27001.
* **Clasificación de Datos:** Matriz de clasificación en 4 niveles (Público, Interno, Confidencial, Restringido) con controles técnicos asociados (DLP, cifrado at-rest/in-transit, RBAC).

#### 🐧 Linux Fundamentals & Hardening
Laboratorio de administración del sistema operativo Linux enfocado en reducción de superficie de ataque.
* **Administración:** Gestión de procesos (`systemd`), permisos estrictos, usuarios/grupos y segmentación de red con UFW.
* **Auditoría:** Análisis de bitácoras de autenticación (`auth.log`) y configuración de servicios críticos como SSH y Apache.

#### 🚀 [TimeLend – Arquitectura Web Full Stack](https://github.com/SantiagoDandrea)
Plataforma descentralizada de productividad desarrollada durante el Aleph Hackathon.
* **Relevancia para Seguridad:** Evidencia de dominio de arquitecturas web modernas (Next.js 15, Express 5, PostgreSQL, Docker y APIs).
